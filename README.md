# Система управления общежитием образовательной организации

Курсовой проект по МДК 02.01 «Технология разработки программного обеспечения».

**Студент:** Витеник П.Л.  
**Тема:** Разработка системы управления общежитием  
**Организация:** Политехнический колледж БГТУ  

---

## Описание проекта

Система предназначена для комплексной автоматизации процессов учёта жильцов, жилого фонда (корпуса, комнаты, койко-места) и процедур заселения/выселения в общежитии образовательной организации.

### Основные пользователи
- **Студент** — подача заявлений на заселение, просмотр статуса, создание заявок на ремонт, оплата проживания, подача заявлений на выселение.
- **Комендант** — учёт номерного фонда, распределение мест, проведение фактического заселения и выселения, контроль и координация ремонтных работ.
- **Воспитатель** — контроль соблюдения правил внутреннего распорядка, учёт контингента проживающих, согласование заявлений, фиксация нарушений.
- **Администратор** — управление учётными записями и правами доступа, тарификация, финансовый контроль (задолженности), аудит и отчётность.
- **Внешние сервисы (External)** — банковский шлюз (онлайн-платежи), сервис SMS/Email-уведомлений.

### Ключевые возможности
- Автоматический поиск свободных мест по заданным параметрам (пол, курс, факультет, тип комнаты).
- Онлайн-подача заявлений и прозрачный трекинг статуса.
- Оформление заселения с генерацией договора найма и привязкой койко-места.
- Учёт и мониторинг состояния номерного фонда.
- Электронный журнал заявок на ремонт бытового инвентаря и помещений.
- Финансовый контроль: учёт платежей, биллинг, формирование реестра задолженностей.
- Процедура выселения с электронным обходным листом и освобождением места.
