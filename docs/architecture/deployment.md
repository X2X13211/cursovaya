# Представление развёртывания: Диаграмма развёртывания

## 1. Узлы и физическая топология
1. **Клиентское устройство (Client Device):** Персональный компьютер коменданта/администратора или смартфон студента. Запускает современный веб-браузер (Chrome, Edge, Firefox, Safari) с клиентским приложением (SPA / HTML5).
2. **Сервер приложений (Application Server, Linux Ubuntu 24.04 LTS):**
  - Прокси-сервер `Nginx` (TLS 1.3 termination, сжатие Gzip, защита от базовых веб-атак WAF).
  - Исполняемый артефакт приложения `dormitory-app.jar` (модульный монолит).
3. **Сервер базы данных (Database Server, PostgreSQL 16 DBMS):**
  - Размещён в **изолированной виртуальной локальной сети (Private VLAN)**.
  - Прямой доступ из публичного интернета закрыт на аппаратном уровне и через файрвол `UFW`. Соединение с сервером приложений защищено внутренним TLS.
4. **Внешний платёжный шлюз (Банк / СБП):**
  - Взаимодействие происходит по защищённому каналу HTTPS mTLS REST API с взаимной валидацией сертификатов.

## 2. Обеспечение требований безопасности персональных данных (152-ФЗ)
- Физическая изоляция сервера БД исключает возможность сканирования портов или прямого перехвата трафика базы из глобальной сети.
- Персональные данные хранятся в БД с применением прозрачного шифрования полей (криптографический модуль `pgcrypto`).
- Доступ администраторов к серверу БД возможен только через защищённый VPN-туннель образовательной организации.
