# Представление реализации: Диаграмма компонентов

## Таблица компонентов системы

| Компонент | Назначение | Ответственный разработчик | Хранилище данных |
|---|---|---|---|
| **Web UI & REST Controllers** | Предоставление пользовательского интерфейса жильцам и персоналу, обработка HTTP-запросов | Разработчик 1, 2, 3 | Stateless (сессии в защищённых JWT) |
| **Security & Identity** | Аутентификация, авторизация по ролям, шифрование ПДн | Разработчик 3 | PostgreSQL (схема `auth`) |
| **Auto-Search Engine** | Алгоритмический подбора свободных мест по критериям | Разработчик 2 | In-memory кэш + PostgreSQL (`rooms`) |
| **Tenancy Core** | Бизнес-логика заселения, генерация договоров, выселение | Разработчик 1 (Тимлид) | PostgreSQL (схема `tenancy`) |
| **Maintenance Module** | Учёт заявок на ремонт и координация мастеров | Разработчик 2 | PostgreSQL (схема `maintenance`) |
| **Billing & Debt Module** | Начисления за проживание, сверка платежей, долги | Разработчик 3 | PostgreSQL (схема `billing`) |
| **Data Access Layer (DAL)** | Единый слой доступа к данным, управление ACID-транзакциями | Разработчик 1 (Тимлид) | PostgreSQL 16 Server |
| **External Payment Gateway** | Внешний сервис онлайн-оплаты банковскими картами / СБП | Внешняя система (Банк) | Внешний процессинг банка |
| **Notification Gateway** | Внешний сервис рассылки SMS и Email оповещений | Внешняя система | Облачный провайдер |
